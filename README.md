# A Two-Grid Characterization of Euler Sampling Accuracy in Flow Matching

Dev D. Goyal ([ORCID 0009-0009-9132-744X](https://orcid.org/0009-0009-9132-744X)). Preprint version 1.1.1, 12 November 2026.

The preprint studies what accuracy at two Euler step counts tells us about a learned velocity field. It explains when taking more steps can reduce the numerical error while increasing the error against the target distribution.
