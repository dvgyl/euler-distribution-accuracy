# When Euler Is Second-Order Accurate in Distribution: Global Criteria and Nonlinear Obstructions

Read the [complete revised manuscript](manuscript.pdf), [IEEE-style main article](ieee_tai_main.pdf), or [complete supplement](ieee_tai_supplement.pdf). ## Main results of the strengthened revision

- **Exact global error and a converse.** For one fixed field under the stated
  smoothness, global Lipschitz and second-moment assumptions, acceleration
  preservation is equivalent to superlinear maximum-node Euler convergence.
  It gives `O(H^2)` on every grid; every other such field has maximum-node
  error `c h + o(h)`, with `c > 0`, on uniform grids. An exact transported
  acceleration formula gives the leading full-Wasserstein coefficient.
- **Nonlinear odd-dimensional rigidity.** A location-scale path generated by
  any finite mixture of nondegenerate Gaussians in odd dimension admits an
  acceleration-preserving generator in the stated globally regular class
  if and only if its mean and positive scale are affine in time. The
  qualifying generator is unique and Euler-exact. Arbitrary nonlinear,
  time-dependent corrections and nonradial, multimodal mixtures are covered.
- **All convex-observable tests can pass while correction is impossible.**
  Convex dilations of symmetric sources pass the complete Hessian-weighted
  minimum-energy hierarchy. Odd-dimensional expanding Gaussian paths can
  nevertheless fail the nonlinear feasibility theorem.
- **Quantitative limits on approximate correction.** The Gaussian case has
  an explicit residual floor at fixed Lipschitz budget. The broader source
  class has a positive compactness-based floor. A hypothetical smooth
  Gaussian escape would require a Jacobian growing at least linearly on
  remote spheres; polynomial corrections reduce to the linear class.
- **Finite endpoint tests cannot certify whole-path order.** Any prescribed
  finite family of smooth schedules can miss a nonzero acceleration defect.
  The explicit cosine example even matches the valid control's second-order
  endpoint coefficient while its maximum-node error is first order. An
  arbitrarily small schedule perturbation exposes the cancellation.
- **Constructive and computational evidence.** The nonradial positive
  construction, Gaussian-start variant, globally solved quartic correction
  search, residual certificates, learned-path bounds and unfavorable solver
  comparisons remain. All **80 tests pass**, including eight new global
  validation tests and independent matrix/100-digit arithmetic checks.

The local projected-defect formula and generic gauge mechanism are credited
to prior work. The follow-up search found two closely related October 2026
papers that the first search missed; the manuscript and
[follow-up literature audit](research/followup_literature_audit.md) explicitly
correct the contribution claims. This is a scoped theorem comparison, not
an exhaustive priority guarantee.

The new Gaussian plots evaluate the exact Gaussian `W2` formula. The
nonradial plots evaluate proven full-Wasserstein **lower and upper bounds**
by quadrature, not an exact nonradial transport solve or interval enclosure.
Heun is slightly more accurate than corrected Euler at equal NFE in the new
nonradial example; RK3 is substantially more accurate. No practical sampling
speedup is claimed.

This package includes the complete paper, its editable sources, and the numerical calculations. The [manuscript](manuscript.pdf) contains the references and appendix. [REPRODUCE.md](REPRODUCE.md) explains how to regenerate the results and build the paper.

The paper studies when changing the velocity field improves Euler's approximation of a distribution. The change must keep the same probability path, which means that the exact distribution is unchanged at every time. Different fields can give these distributions through different particle trajectories.

Under the stated assumptions, Euler has a second-order bound on distribution error. The nonlinear example achieves this rate, although its particle error remains first order. Particle error compares numerical and exact particles from the same starting point. Distribution error allows other pairings, so its rate can be different.

The calculations use exact formulas for the distributions or deterministic numerical quadrature, which approximates an integral by a weighted sum. The original controls need no learned model or random sample. The revision additionally includes a seeded noisy one-coefficient velocity-regression experiment.

NFE is the number of function evaluations, where each evaluation computes the velocity field. In the data, `base` denotes the field without rotation and `corrected` denotes the field with rotation. The `heun_cubic_cancellation` setting uses a separate rotation coefficient calibrated for Heun.

The Gaussian sensitivity refinement file contains 66 coefficient comparisons, including 42 rows with `passed=False`. These rows fall outside the coefficient tolerance at the stated step counts. The reproduction check requires agreement only on the finest grid for each rotation ratio, and all six of these rows pass. The [numerical comparison criteria](REPRODUCE.md#numerical-comparison-criteria) define this test and the separate convergence-order test.

This includes 63 tests, all numerical calculations, eight figure PDFs, and the generated tables and macros. The `make reproduce` entries share this single runtime; individual figures and numerical tables were not timed separately.

The total of 53.4 s excludes dependency installation, Python imports before timing starts, and the manuscript build. A separate manuscript build took 1.90 s with cached Tectonic resources. These times depend on hardware and system load and do not measure a sampler speedup.

The tests compare separate calculations, including Cartesian and polar updates and Gaussian matrix and scalar formulas. They check the changes caused by finer quadrature and more accurate reference calculations, along with error orders and field evaluation counts. Deliberately incorrect updates and solver stages check whether the tests detect errors. These numerical checks test the implementation. The paper gives the mathematical proofs.
